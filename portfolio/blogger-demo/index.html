대신 블로거 데모

Claude Code에 /blog-review 성수동 숯결갈비, 웨이팅 30분 / 갈빗살 강추처럼 장소와 메모를 보내면, 사진을 정리하고 사진을 직접 보며 후기를 쓴 뒤, 확인을 받고 네이버 블로그에 발행합니다.

이 페이지는 브라우저 안에서만 동작하는 체험판입니다. 가게와 사진은 입력한 장소로 만들어 낸 가상의 예시이며, 실제 Claude Code·네이버 블로그에는 연결되지 않고 아무것도 발행되지 않습니다. 실제 도구는 Claude가 사진을 보고 매번 새로 쓰지만, 데모는 미리 준비한 문장으로 흐름만 보여 줍니다.
~/dev/대신 블로거Claude Code
눌러서 입력
output/
사진을 정리하면 여기에 01.jpg, 02.jpg … 순서로 놓입니다.
후기를 쓰면 여기에 preview.html이 그려집니다.
사진 정리폴더·iCloud·휴대폰(QR)에서 받은 사진을 찍은 순서대로 01.jpg…로 바꾸고, HEIC 변환과 600px 축소를 합니다. 동영상은 회전 보정과 얼굴 모자이크를 거칩니다.
사진 보고 쓰기Claude Code가 사진을 모두 열어 보고, 보이는 것과 메모만으로 후기를 씁니다. 가격·영업시간처럼 확인되지 않는 내용은 지어내지 않습니다.
미리보기 확인첫 사진은 썸네일이 되도록 음식 사진으로 두고, 미리보기를 보여 준 뒤 수정 요청을 반영합니다.
확인 후 발행Playwright로 에디터에 사진·지도·태그를 넣고, 발행 직전 화면을 캡처해 승인받은 뒤에만 발행합니다.
